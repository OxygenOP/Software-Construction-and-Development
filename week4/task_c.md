# Week 4 - Part C: Module Design

Proposed structure (you may change it if you justify the change):

```
student_marks/
  main.py
  validation.py
  calculations.py
  display.py
```

Answer these:

1. Why does each module exist - what would go wrong if it did not?
2. Which functions belong in `calculations.py`, and why those?
3. Should `display.py` calculate the grade? Why or why not?
4. What should `main.py` coordinate, and what should it *not* do?
5. Which implementation details should other modules not need to know?
