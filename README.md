# Software Construction and Development

Coursework repository for **Software Construction and Development** (Python, 3 credit hours, lab-based),
organised by teaching week as requested by the class representative.

## Structure

| Folder | Topic | Required artefacts |
|---|---|---|
| `week1/` | Introduction to Software Construction | `billing_system.py`, `employee_salary_calculator.py` |
| `week2/` | Writing Good Functions | `student_result.py`, `salary_calculator.py`, `PROJECT_PROPOSAL.md` |
| `week3/` | Writing Understandable Code | `refactor_nesting.py`, `bonus_eligibility.py`, `check_access_refactor.py` |
| `week4/` | Modularity and Separation of Concerns | `student_marks/` package + four written artefacts |

Each week's `README.md` states what that week requires and what "done" looks like, taken from that
week's lecture material and the Week 4 laboratory assignment.

## Conventions

- Python 3; one file per artefact, snake_case names, no `main()` doing everything
- Every artefact runs standalone (`python week2/student_result.py`)
- Behaviour is verified before and after any refactor and the evidence is recorded
- Commits are small and describe what changed and why
